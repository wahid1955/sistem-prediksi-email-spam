# Sistem Klasifikasi Email Spam (Naive Bayes)

Implementasi kode Java berdasarkan Class Diagram Tugas 10 Mata Kuliah Rekayasa Perangkat Lunak.

## Anggota Kelompok & Pembagian Branch

- Wahid Afnan Apriyanto (Ketua) — `feature/user-admin` (`User.java`, `Admin.java`, `LaporanPrediksi.java`)
- Sena Andra Abyan — `feature/data-hasil` (`Email.java`, `DataEmailTraining.java`, `HasilPrediksi.java`)
- Achmad Lutfi Alfiansyah — `feature/naive-bayes` (`Preprocessing.java`, `ModelNaiveBayes.java`)

## Cara Menjalankan

1. Clone repository: `git clone https://github.com/wahid1955/sistem-prediksi-email-spam.git`
2. Buka folder proyek menggunakan VS Code atau IDE Java (NetBeans/IntelliJ).
3. Kompilasi dan jalankan file `.java`.
